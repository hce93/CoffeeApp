# CoffeeApp

A web based app that replicates reddit specifically for coffee

## Features
- User portal allowing users to save coffees, write personal reviews, save other user's reviews.
- Dynamic home page which displays new coffees, top rated coffees, new reviews and popular reviews.
- User diary page allowing users to keep a track of the coffee's they have brewed, add any personal notes (such as methods used).
- Reddit style comment feed for every coffee or reviews added to the app.
